# Research and design decisions

1. **Repository baseline**: Employee directory options and compensation detail exist; no analytics endpoint, rate storage, reporting-currency setting, or authorization. App navigation is URLSearchParams state, not React Router. Existing UI primitives are predominantly Coss/Base UI; Card is still local legacy. Reuse it here because migration is not small and is not necessary for this feature.
2. **Handoff interpretation**: Screenshot is S07 with filter strip, partial-data callout, four metric cards, histogram, breakdown, methodology. Its 10,482 employees, USD totals, Sarah Jenkins, UAE rate gap and notification are illustration, not data. The current repo has seed data in five countries and no FX rates.
3. **FX, revised 2026-10-05**: Analytics is fixed to USD and uses one documented Federal Reserve H.10 reference set dated 2026-09-25 for EUR, GBP, INR and SGD ([official release](https://www.federalreserve.gov/releases/h10/current/)). The source publishes USD per EUR/GBP and source currency per USD for INR/SGD, so the latter are inverted with Decimal. Store source/target/date/rate/source/approved and use that exact date regardless of compensation as-of selection. Convert via Decimal then round half-even to USD cents. No rate means exclusion and Partial. Same-currency USD amounts need no rate. This is an analytics estimate, not a transaction FX quote.
4. **Population**: Joining <= as-of and termination empty or >= as-of. Current status filter further narrows; group attributes are current stored attributes. Effective package uses inclusive dates. No historical org membership inference.
5. **Money**: Annualize in source minor units. Convert annualized major amount with Decimal using source/target decimal places. Base metric cohort has hourly, no-package and missing-FX exclusions. Variable/allowance metrics have their own exclusions; target compensation requires all components.
6. **Chart and composition**: User explicitly requires Recharts. Use BarChart with neutral bars, accessible label, tooltip and a Coss Table equivalent. Reuse Coss Button/Select/Input/Table/Sheet; no new ShadCN component. Recharts is the only new frontend dependency.
7. **Local access**: No permission model is available. Keep the limitation explicit in API descriptions and implementation status, while omitting development-environment notices from the product UI. Do not claim the endpoint is secured.
